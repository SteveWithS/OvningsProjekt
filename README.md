# OvningsProjekt

Detta är mitt övningsprojekt jag gjorde. Den är på en arduino och poängen med den är att ha en ledskärm som vissar kl och temp. Den har också en servo som ska rikta sig åt tempens håll och 3 lampor som lysser vid olika grader. Under 10 grader C = blå, över 25 grader C = röd, där emellan = grön.
